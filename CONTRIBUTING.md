# Contributing to MultiConnect

Thank you for your interest in contributing to MultiConnect!

## getting Started

1.  Clone the repository.
2.  Open the project in Visual Studio 2022 or VS Code.
3.  Configure with CMake.

## Code Style

We use `clang-format` with Google style (modified for 4-space indentation). Please ensure your code is formatted before submitting a PR.

## Pull Requests

1.  Fork the repository.
2.  Create a feature branch.
3.  Commit your changes.
4.  Push to your fork and submit a Pull Request.

## Reporting Issues

Please use the GitHub Issues tab to report bugs or request features.
